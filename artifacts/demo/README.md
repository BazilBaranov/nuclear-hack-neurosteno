# Видеодемонстрация

[Смотреть / скачать MP4](neurosteno-demo.mp4) · [JSON, сохранённый через интерфейс](transcript.json)

Запись экрана **Honor 200 / Android 16**, установленный optimized APK,
код приложения `6a445ae`. Модели подготовлены заранее; в момент обработки
авиарежим включён, Wi-Fi и мобильная передача данных отключены.
После демонстрации настройки восстановлены.

| Время ролика | Что показано |
|---|---|
| 00:00–00:09 | Загруженные модели |
| 00:09–00:39 | Выбор обработки, новый запуск и стадии на настоящем устройстве |
| 00:39–00:46 | Реплики, метки участников и временные границы |
| 00:46–01:05 | Изменение метки одной реплики на `S1`, сохранение |
| 01:05–01:10 | Возврат после экспорта JSON |
| 01:10–01:17 | Стоп-кадр с моделями, временем стадий и CPU-диагностикой |

Монтаж удаляет паузы и системный проводник с личными файлами.
Участок обработки идёт в реальном времени; результат не подставлен заранее.
Последний кадр — подписанный статичный скриншот той же обработки.
Звуковой дорожки нет; пояснения встроены в кадр.

Вход — локальный русский речевой пример проекта (15,125 с), SHA-256:
`4c9b5b07df23ea50cc3123ebf41e9601e2560d9ba5ea181aff4cda3ac271576a`.
Само аудио не распространяется. В `transcript.json` — настоящий экспорт после
редактирования первой метки; это демонстрация формата, не эталон качества.
Показанные предупреждения диаризации сохранены, ошибки моделей не скрываются.
