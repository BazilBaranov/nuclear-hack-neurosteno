# Исходный код

Платформа решения — **Android**. Карта исходников и инструкции:
[mobile/README.md](mobile/README.md).

Структура отчётных материалов следует шаблону Nuclear IT Hack.
Рабочий Gradle-модуль сохранён в корневом [app/](../app/), чтобы команды сборки
и путь `app/build/outputs/apk/optimized/app-optimized.apk` оставались прежними.
Исходники не дублируются.
