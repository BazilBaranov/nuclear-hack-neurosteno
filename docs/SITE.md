# Публичный сайт проекта

Адрес: https://neurosteno-nuclear-hack.honey-kid-1285.chatgpt.site

Светлая страница с бирюзовым акцентом, показателями, настоящей видеодемонстрацией,
переключением экранов, светлой/тёмной темой и отдельными страницами документации.
Визуальный ориентир: https://jehb4ik.github.io/PANTHER-FLARE2026/.

Каноническая страница: `docs/index.html`; изображения: `docs/assets/`.
Сборка требует Python 3.9+ и Python Markdown (`python3-markdown`):

```bash
python3 scripts/build-showcase.py /path/to/neurosteno-site/dist
```

Экспорт включает только разрешённый набор отчётных материалов: 9 документов,
описания артефактов, очищенные JSON/CSV, демонстрационное видео и изображения.
APK и код Android не копируются в сайт. APK распространяется через Releases.
Исходный GitHub-репозиторий и его релиз остаются приватными; это явно указано на странице.

Проверки перед публикацией: локальные ссылки и ресурсы, мобильная/настольная
верстка, переключение темы и скриншотов, видео и переходы по главам.
Хостинг: Sites, отдельный публичный проект. Секреты и приватные дампы не публикуются.
