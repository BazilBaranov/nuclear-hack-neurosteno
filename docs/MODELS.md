# Модели: загрузка и локальное исполнение

Подготовка и размеры: [model-downloads.md](model-downloads.md). Текущие доказательства выполнения на устройствах: [протоколе проверки](VALIDATION.md). Веса не упакованы в APK; сеть нужна для подготовки, затем обработка работает локально.

| Назначение | Реализация |
| --- | --- |
| ASR RU/EN | Whisper tiny/base/small; Zipformer RU 2025; GigaAM-v3 RNNT RU через sherpa-onnx. |
| Определение языка | Отдельный Whisper tiny в режиме «Авто». |
| Диаризация | Pyannote segmentation 3.0 + TitaNet-S либо NVIDIA Nemotron-3-Diarization GGUF Q8. |
| Подавление шума | GTCRN ONNX после нормализации аудио. |
| Одновременная речь | VoxLock enrollment + chunk INT8; нужен чистый образец голоса из той же записи. |
| Пунктуация | Qwen3.5-0.8B GGUF Q4_K_M через llama.cpp. Защита отклоняет изменения слов и чисел. |

Пунктуация, подавление шума и разделение одновременной речи включаются отдельными чекбоксами. Сервис проверяет наличие весов для выбранных функций. Устаревшие модели скрыты из списков, их идентификаторы сохранены для старых записей.

## Целостность и выбор

`ModelCatalog.kt` задаёт HTTPS-источник, ожидаемые размер и SHA-256 каждого файла. Большинство источников закреплены ревизией; release-артефакты GTCRN/VoxLock защищены ожидаемым хешем. `ModelStore` потоково записывает временный набор, проверяет байты и хеш и атомарно публикует каталог с readiness marker. Проверка готовности при опросе UI использует marker/размеры и не пересчитывает полный хеш гигабайт весов каждый раз; повреждение файла с тем же размером после установки не обнаруживается таким быстрым опросом.

Удаление/замена моделей ограничены на время обработки. Ручной ASR должен соответствовать определённому языку; Auto рассматривает только готовые совместимые модели. Приоритет — эвристика, не опубликованный WER-рейтинг. Выбор ASR/диаризатора сохраняется в запуске и используется при повторе. `CompletedRun` записывает ID/хеши реально использованных моделей.

## Вычислители и зависимости

- ONNX: локальный AAR `com.k2fsa.sherpa:onnx:2.0.1-nnapi3` включает sherpa 2.0.1 и ORT 1.28.2. NNAPI используется до Android 13 включительно.
- Дополнительные веса LiteRT для Android 14+ скачиваются отдельно. [Совместимые модели и фолбеки](acceleration.md).
- Платформа: Android API 28+, NDK 28.2.13676358, arm64-v8a/x86_64. Детали порта: [nemotron-android.md](nemotron-android.md), [local-llm-runtime.md](local-llm-runtime.md).

Модель на GPU не обязательно быстрее CPU; наличие NNAPI не даёт одинакового результата на Qualcomm, MediaTek и Google Tensor. Скорость, память, качество и offline acceptance относятся к конкретным измерениям в [протоколе проверки](VALIDATION.md). Исторические результаты прежней CPU-only сборки не подтверждают новую GPU/LLM-сборку.
