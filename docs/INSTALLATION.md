# Установка и использование

[← Главная](../README.md) · [Модели](MODELS.md) · [Ограничения](LIMITATIONS.md)

## Быстрый старт

1. Скачайте [neurosteno-arm64.apk](https://github.com/BazilBaranov/nuclear-hack-neurosteno/releases/latest/download/neurosteno-arm64.apk).
   Файл хранится в **Releases**, отдельно от исходного кода.
2. Откройте APK на Android и разрешите установку из выбранного источника.
3. Откройте **Расшифровка**, выберите аудио и язык (по умолчанию русский).
4. Нажмите **Расшифровать**, затем **Открыть результат**. При первом запуске
   обработки v0.3.0 приложение извлечёт из APK Whisper small и Pyannote/TitaNet.

**Платформа:** Android 9+ (API 28), 64-разрядный ARM (`arm64-v8a`).
Сдаваемый APK не подходит для x86-эмулятора; для него нужна отдельная сборка.
Функциональная проверка проведена на Honor 200 / Android 16.

## Какие модели скачать

| Сценарий | Обязательные модели | Примерный размер весов |
|---|---|---:|
| Русский или английский, язык выбран вручную | Whisper small + Pyannote/TitaNet уже в APK | 0 МБ загрузки |
| Определение языка «Авто» | Дополнительно Whisper tiny | +104 МБ |
| Пунктуация локальной LLM | Дополнительно Qwen 3.5 0.8B | +533 МБ |
| Подавление шума | Дополнительно GTCRN | +0,54 МБ |
| Разделение одновременной речи | Дополнительно VoxLock | +79 МБ |
| Диаризация Nemotron | Вместо Pyannote/TitaNet — Nemotron Q8 | 107 МБ |

Размеры десятичные, округлены; при обновлении нужно место для временной копии.
Для полного демонстрационного набора оставьте около 2 ГБ свободного места.
На время загрузки держите приложение открытым. SHA-256 проверяется автоматически.
После подготовки моделей сеть для обработки не нужна.

## Записать или импортировать звук

**Запись:** вкладка «Запись» → «Записать» → разрешить микрофон →
«Остановить и сохранить». WAV сохраняется в `Загрузки/neurostenografist`.
Разрешение уведомлений позволяет видеть состояние фоновой задачи.

**Импорт:** вкладка «Расшифровка» → «Выбрать аудио» → файл через системный проводник.
Поддерживается PCM16 WAV; остальные форматы зависят от декодеров Android.
Максимум — 30 минут, фактический предел может быть ниже из-за доступной памяти.

## Настроить обработку

- «Русский» / «Английский» пропускают автоматическое определение языка.
- «Авто» использует Whisper tiny для определения языка; это не замена основного ASR.
- Whisper small распознаёт русский и английский. GigaAM-v3 и Whisper base доступны для отдельной загрузки.
- «Автоматически по языку» выбирает из установленных совместимых моделей.
- Pyannote/TitaNet и Nemotron — альтернативные диаризаторы.
- Пунктуация, подавление шума и разделение одновременной речи включаются отдельно.
  Для каждого выбранного пункта нужны соответствующие веса.

Во время обработки приложение показывает стадию. Кнопка «Отмена» отменяет работу
на ближайшей поддерживаемой границе; отдельный native-вызов может завершиться позже.

## Проверить, исправить и экспортировать

Результат содержит говорящего, временные границы и текст каждой реплики.

- **Слушать** — воспроизвести исходный фрагмент.
- **Изменить** — исправить текст, имя участника и границы выбранной реплики.
- **Распознать фрагмент заново** — повторить ASR для одной реплики, сохранив остальные.
- **Подробности обработки** — увидеть модели, времена стадий и фактический вычислитель.
- **Сохранить JSON** — выбрать место через системный диалог.
- **Поделиться** — передать JSON через выбранное приложение. Это явное действие пользователя.

Сохранённые запуски доступны через меню → «История».
[Формат JSON и восстановление после ошибок](PROTOCOL.md).

## Установка через ADB

```bash
adb devices
adb -s SERIAL install -r neurosteno-arm64.apk
```

Пакет: `dev.neurostenografist.ultra`, версия `0.1.0-ultra-optimized`.
APK подписан debug-сертификатом сборочной машины, но не является debug/test-only сборкой.
Обновление требует совпадения подписи. При конфликте подписи сначала экспортируйте
нужные результаты: удаление старой установки удалит её приватные модели и данные.

Скачайте [SHA256SUMS.txt](https://github.com/BazilBaranov/nuclear-hack-neurosteno/releases/latest/download/SHA256SUMS.txt)
в одну папку с APK. Из этой папки выполните проверку:

```bash
sha256sum -c SHA256SUMS.txt
```

## Сборка из исходников

Нужны Linux x86_64, JDK 17, Android SDK 35, build-tools 35.0.0,
NDK 28.2.13676358, CMake 3.22+, Ninja, Python 3, curl, unzip, patch и dpkg-deb.
`JAVA_HOME` должен указывать на JDK 17, `ANDROID_HOME` — на Android SDK.

```bash
git clone git@github.com:BazilBaranov/nuclear-hack-neurosteno.git
cd nuclear-hack-neurosteno
export JAVA_HOME=/path/to/jdk-17
export ANDROID_HOME=/path/to/android-sdk
export VULKAN_SDK="$PWD/artifacts/build/vulkan-tools/usr"

./scripts/prepare-nnapi.sh &&
  ./scripts/prepare-vulkan-tools.sh &&
  ./scripts/prepare-bundled-models.sh &&
  ./scripts/build.sh :app:assembleOptimized
```

Результат: `app/build/outputs/apk/optimized/app-optimized.apk`.
Для x86_64 добавьте `-PappAbi=x86_64`; для двух ABI — `-PappAbi=universal`.
Первая сборка скачивает закреплённые зависимости. Веса моделей не входят в сборку.
