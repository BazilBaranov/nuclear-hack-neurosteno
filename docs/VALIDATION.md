# Проверка переноса, 8 ноября 2026

Исходная версия: GitLab `plan`, коммит `e6987c4`.
Проверяется чистая копия исходников без APK, весов, старого build-кэша и дампов устройств.

Pixel повторно не тестируется по указанию владельца: его результаты приведены
в исходной документации NNAPI/Nemotron и не выдаются за новый замер.

## Изменения при переносе

GigaAM явно задаёт `modelType=nemo_transducer`. Это исключает дополнительную
CPU-сессию энкодера, которую sherpa создаёт для автоопределения архитектуры.
Маршрутизация NNAPI энкодера / CPU decoder+joiner сохранена.

Исправлена передача linker version-script sherpa JNI через `target_link_options`.
На исходном `LINK_FLAGS` чистая сборка падала в пути с пробелами
(`Нейро-стенографист _ Hex.team`); после исправления тот же pipeline завершился успешно.
Повторное применение патчей JNI и GigaAM не меняет уже исправленные исходники.

На Honor 200 (`Build.DEVICE=HNELIX`) Qwen по умолчанию использует CPU: проверенный
Vulkan-драйвер падает при вычислении и может блокировать последующие GPU-сессии.
Явный запрос GPU оставлен для диагностики; поведение Pixel и остальных устройств не изменено.
Регрессионный тест проверяет две независимые загрузки Qwen с настройками по умолчанию.
На старой сборке он упал на выборе GPU; на исправленной прошёл, оба текста совпали с эталоном.

## Honor 200

HONOR ELI-NX9, Snapdragon 7 Gen 3 / Adreno 720, Android 16 (API 36).
Модели проверены по SHA-256. Результаты ниже относятся к одному устройству и коротким контрольным записям, не к общей оценке качества.

- Qwen 3.5 CPU: точный результат `Привет, как дела?`, повтор совпадает.
- Qwen 3.5 с запросом GPU: ошибка вычисления, корректный повтор на CPU с тем же текстом. Аппаратное исполнение не подтверждено.
- Nemotron CPU: 15,125 с аудио за 19,49 с вместе с загрузкой, два диктора.
- Nemotron с запросом GPU в отдельном процессе: `vk::Device::createComputePipeline: ErrorUnknown`,
  затем CPU за 12,96 с (включая неудачную попытку GPU). Результат совпал с CPU:
  2 диктора, speaker-frame error 0, разница overlap 0. Это не ускорение GPU;
  холодные/прогретые времена напрямую не сравниваются.
- Последовательность Qwen GPU → Nemotron GPU в одном процессе не завершилась за
  3 минуты и была остановлена. Этот набор не считается успешно пройденным.
- ONNX LID/ASR/диаризация прошли на CPU. Аппаратный драйвер NNAPI не обнаружен;
  профиль содержит 0 исполнений NNAPI. Pixel-специфичная проверка пропущена по условию.
- 20 проверок навигации, экспорта, разрешений, настроек и декодирования WAV/AAC прошли.
- Навигация по синтетическому результату из 2000 реплик прошла отдельно после разблокировки
  экрана. Два предыдущих запуска не прошли из-за блокировки экрана; их не считаем
  измерением производительности. Численных метрик плавности из этих запусков нет.
