# Формат данных и жизненный цикл обработки

[← Главная](../README.md) · [Архитектура](ARCHITECTURE.md)

Шаблон организаторов содержит раздел акустического протокола передачи файлов.
Наш кейс — локальная стенография: акустическая передача файлов не используется.
Здесь описан контракт входа, обработки и экспорта.

## Вход и временная шкала

Микрофон записывает mono WAV. Импорт поддерживает PCM16 WAV и контейнеры,
которые декодирует Android MediaCodec. Аудио приводится к mono PCM 16 кГц.
Временные границы всегда относятся к исходной записи, а не к склеенным фрагментам.

## Экспорт JSON

Корневой объект содержит массив `transcript`:

```json
{
  "transcript": [
    {
      "speaker_id": "speaker_1",
      "start_ms": 800,
      "end_ms": 2400,
      "text": "Пример формата реплики."
    }
  ]
}
```

Это пример схемы, не результат измерения. Настоящий экспорт из видеодемонстрации:
[transcript.json](../artifacts/demo/transcript.json).

| Поле | Тип и смысл |
|---|---|
| `speaker_id` | Непустая строка; метка участника, не распознавание личности |
| `start_ms` | Целое число миллисекунд, ≥ 0 |
| `end_ms` | Целое число миллисекунд, > `start_ms`, в пределах записи |
| `text` | Текст реплики после ASR, разрешённой пунктуации и пользовательских правок |

У тишины допустим `{"transcript": []}`. Одновременные реплики могут пересекаться
по времени. Имена спикеров локальны для одной записи; совпадение меток между
разными записями не означает одного и того же человека.

## Состояния и восстановление

`created → running → completed` либо `failed / interrupted / cancelled`.
Точный набор состояний задаёт [RunStore](../app/src/main/java/dev/neurostenografist/data/RunStore.kt).
Результат сохраняется атомарно. После смерти процесса незавершённая обработка
не выдаётся за успешную. Повтор реплики заменяет старый текст только после успеха.

## Ошибки и совместимость

Повреждённое аудио, несовместимый язык/ASR и отсутствующие веса дают явную ошибку.
Неоднозначная диаризация и CPU fallback сохраняются в диагностике запуска.
Слова и числа, изменённые локальной LLM, не принимаются: остаётся ASR-текст.
Экспорт не включает внутренние пути, веса или запись звука.
