## Время обработки на Honor 200

HONOR ELI-NX9, Snapdragon 7 Gen 3 / Adreno 720, Android 16 (API 36).
Веса проверены по SHA-256. Один прогон каждой записи, без доверительных интервалов.

| Вход | Модели | Длина | Полный проход | RTF |
|---|---|---:|---:|---:|
| Русская речь | GigaAM-v3, Pyannote/TitaNet, GTCRN, Qwen 3.5 | 15,125 с | 14,179 с | 0,937 |
| Английский диалог AMI | Whisper base, Nemotron, GTCRN, VoxLock, Qwen 3.5 | 60 с | 109,805 с | 1,830 |
| Тишина | LID/диаризация и GTCRN; пустой результат | 3 с | 1,624 с | 0,541 |

RTF = время обработки / длительность входа; меньше 1 — быстрее длительности записи.
Русская ASR-стадия отдельно заняла 2,366 с. Повтор одной реплики — 6,227 с.
Полный проход включает подготовку, диаризацию, LID, ASR и выбранную обработку.
[CSV с числами](../artifacts/test-results/results.csv).

## Аппаратные вычислители

- **CPU Honor:** весь проверенный pipeline работает, включая реальную Qwen 3.5.
- **Qwen Vulkan / Adreno 720:** ошибка вычисления, CPU fallback возвращает правильный
  контрольный текст. В обычном режиме Honor сразу использует CPU.
- **Nemotron Vulkan / Adreno 720:** `createComputePipeline: ErrorUnknown`; в свежем процессе
  срабатывает CPU fallback, результат совпадает с CPU по контрольным интервалам.
- **Последовательный GPU-прогон:** после ошибки Qwen принудительный Nemotron GPU
  не завершился за 3 минуты; остановлен. Этот прогон не считается успешным.
- **NNAPI Honor:** аппаратный драйвер не обнаружен; профиль подтверждает 0 исполнений NNAPI.
- **Pixel 9 Pro:** повторно не проверялся при переносе. Исторические результаты
  описаны в [NNAPI](onnx-acceleration.md) и [Nemotron](nemotron-android.md).
  Pixel-only instrumentation на Honor пропущена по условию.
- **MediaTek:** физического устройства для проверки не было.
