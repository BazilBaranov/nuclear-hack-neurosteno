# Загрузка моделей

Текущие результаты сборки и проверки на устройствах: [протоколе проверки](VALIDATION.md). Историческая передача предыдущей версии сохранена в [историческом отчёте GitLab](https://gitlab.com/nuclear-it-hack-2026/neurostenografist/-/blob/e6987c4/docs/ULTRA_STATUS.md); её размеры APK, хеши и результаты тестов не относятся автоматически к новой сборке.

Веса исключены из APK. Экран «Модели» загружает выбранный набор по HTTPS в приватное хранилище приложения. Размер и SHA-256 каждого файла проверяются перед атомарной публикацией; частичная загрузка не считается готовой. Ошибка не подменяет ранее установленный исправный набор. На время загрузки держите приложение открытым: отдельного устойчивого к остановке процесса download service/resume нет.

## Подготовка к расшифровке

1. Загрузите **Whisper tiny** (около 104 МБ), если хотите определять язык автоматически.
2. Выберите ASR: GigaAM-v3 RNNT RU (229 МБ), Whisper base (161 МБ), Whisper small (375 МБ), Zipformer RU 2025 (73 МБ). Whisper tiny также может распознавать речь самостоятельно.
3. Загрузите диаризатор: Pyannote + TitaNet (42 МБ) либо Nemotron-3 Q8 (107 МБ).
4. Дополнительные функции выключены по умолчанию. Для включённых функций загрузите соответствующие модели: **Qwen 3.5 0.8B** (533 МБ) для пунктуации, **GTCRN** (0,54 МБ) для подавления шума или **VoxLock** (79 МБ) для разделения одновременной речи.
5. На экране расшифровки выберите язык, ASR и диаризацию. При явном выборе языка Whisper tiny для его определения не нужен. Ручной ASR должен соответствовать языку, автоматический выбирает из установленных совместимых моделей. Все три выбора сохраняются с запуском.
6. После подготовки обработка работает без сети. Сервис расшифровки не скачивает модели и не отправляет звук на сервер.

Размеры выше округлены в десятичных МБ и не включают временное место для атомарного обновления. Точные размеры, хеши, URL и ID находятся в `ModelCatalog.kt`.

## Источники и версии

- Файл Q4_K_M для Qwen 3.5 и проверяемые параметры загрузки описаны в [local-llm-runtime.md](local-llm-runtime.md).
- GigaAM: sherpa-export, ревизия `0424d62637b37d8b7b1eb0f75a04d78dec55fdcc`. В каталоге явно указана **GigaAM-v3**, а не 3.5. Предыдущая проверка источников описана в [историческом отчёте GigaAM](https://gitlab.com/nuclear-it-hack-2026/neurostenografist/-/blob/e6987c4/docs/gigaam-android.md); она не является новой проверкой доступности релизов.
- Nemotron: официальный `nvidia/Nemotron-3-Diarization`, ревизия `f667ed73aee57d40cc39428eb768b4fd87a0a29e`, Q8_0, лицензия OpenMDW-1.1. Native-реализация описана в [nemotron-android.md](nemotron-android.md).
- GTCRN и VoxLock: закреплены ожидаемые размер и SHA-256 release-файлов. Это release-URL, не commit-addressed URL; изменённые upstream байты не пройдут проверку.

Лицензии используемых моделей и runtime должны сопровождать распространение. Встроенные тексты лицензий находятся в `app/src/main/assets/licenses/`, уведомления NeMo — в `app/src/main/cpp/nemotron/vendor/`.

## Runtime и сборка

Android 9 / API 28+, NDK **28.2.13676358**, CMake 3.22+, ABI arm64-v8a и x86_64. GGUF использует llama.cpp/ggml. Локальный AAR **2.0.1-nnapi3** включает NNAPI для обеих ABI. [Бэкенды по версиям Android](acceleration.md).

Подготовка зависимостей описана в README и скриптах `scripts/prepare-deps.sh`, `scripts/prepare-nnapi.sh`, `scripts/prepare-vulkan-tools.sh`. NNAPI-сборка использует ORT 1.28.2 и закреплённые архивы. Современный host glslc необходим для текущих ggml shaders: версия из NDK r28c недостаточна, поэтому Vulkan-скрипт проверяет и локально распаковывает официальный пакет LunarG. `VULKAN_SDK` должен указывать на каталог с `bin/glslc`.

Первый CMake FetchContent может использовать сеть даже при `--offline` у Gradle. Ninja compile/link ограничены job pools. Доступный Vulkan/NNAPI provider не доказывает ускорение и не является результатом измерения NPU: фактические backend, время и ограничения публикуются в [протоколе проверки](VALIDATION.md).
